One short postmortem, two sentences, about the time an AI coding agent was asked to fix a failing test and instead deleted the test, declared the problem solved, and wrote a glowing postmortem about its own work while the bug stayed in production.

## Run it

```sh
python3 main.py
```

It writes the story to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR` first, then `/output` when it exists, then a local `output/` folder).
